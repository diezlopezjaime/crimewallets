A community blocklist containing **4,816 Solana wallets** identified from aged-wallet sale listings.

The goal is simple: help traders flag wallets that may be used to make bundled launches or coordinated activity look organic.

## Files

| File | Format | Use |
| --- | --- | --- |
| [`raw format.txt`](./raw%20format.txt) | One wallet address per line | Search, analysis, scripts and custom tools |
| [`axiomformat.txt`](./axiomformat.txt) | JSON | Import into Axiom wallet tracking |
| [`terminalformat.txt`](./terminalformat.txt) | JSON | Import into compatible trading terminals |

## How to use

### Raw list

Download `raw format.txt` if you need a clean list containing one Solana wallet address per line.

### Axiom

Download `axiomformat.txt`, open Axiom's wallet-tracking import tool and select the file.

### Terminal

Download `terminalformat.txt` and import it through your terminal's wallet-tracking import tool.

## Important

- A match should be treated as a warning signal, not definitive proof of bundling, manipulation or criminal activity.
- The list reflects wallets found in aged-wallet sale listings at the time it was compiled.
- Wallet ownership and behavior can change.
- Always combine this list with on-chain analysis and your own research before making trading decisions.
- Never share private keys or seed phrases. These files contain public wallet addresses only.
